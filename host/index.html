Recovery

Changed documents are saved about every minute. Recovery copies stay in this browser profile, not online. If the browser or tab crashes, open this page again and VectorCraft offers to recover them.

Anyone using this same profile may recover its copies. Private browsing or school profile cleanup can erase them. Keep saved .vectorcraft copies too (File → Save downloads one).

Fonts & import

Load font files

Choose .ttf or .otf files from your computer. They stay in this page session and are not uploaded.

Save your work first. Applying fonts restarts the editor. Load them again after reopening this page.

Fonts from this PC

Use fonts installed on this PC. Font names and files stay in this browser session; they are not uploaded.

Save your work first. Enabling or disabling PC fonts restarts the editor.

Browse the font library

All of these fonts are already in VectorCraft's font menus (they finish loading a few seconds after the editor opens). Choose a category, copy a font name, then search for it in the Character panel's font menu.
